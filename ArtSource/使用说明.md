# 2048 简洁配色素材

预览图：[2048_preview.png](2048_preview.png)。图片由本项目中的 `generate_simple_2048.py` 生成，可自由修改颜色并重新生成。

Unity 素材位于 `Assets/Art/2048Simple`：

- `board_with_slots.png`：已经画好 4×4 空格的棋盘。将 UI Image 设为 1024×1024，数字方块覆盖其上即可。
- `board_panel.png` + `cell_empty.png`：适合自己用 GridLayoutGroup 搭建棋盘。
- `tile_2.png` 至 `tile_2048.png`：带数字的方块，适合先快速做不同数值的预制体。
- `tile_bg_2.png` 至 `tile_bg_2048.png`：只有底色，适合配合 TextMeshPro 动态显示数字。
- `score_panel.png`、`button_primary.png`：分数框与按钮底图；文字建议在 Unity 里添加。

棋盘为 1024×1024，格子为 216×216，外边距及格子间距均为 32。显示在屏幕上时可以将整块棋盘等比缩小。所有图片均为 PNG，透明圆角；导入 Unity 后把 Texture Type 设为 **Sprite (2D and UI)**，在 uGUI 的 Image 组件中选择对应 Source Image。

提示：如果使用 `board_with_slots.png`，无需再在棋盘下方摆放 16 张 `cell_empty.png`。数字方块的行号 0 对应棋盘最上方。
